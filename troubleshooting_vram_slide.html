Trouble Shooting : VRAM OOM

⚠️ 문제 정의 및 원인
  • 답변 첫 글자도 안 나온 채 30초 넘게 멈춰 있다가 타임아웃 으로 끊겼다.
  • Ollama 가 GPU 자리를 못 잡고 CPU 로 떨어져 평소보다 20배 느리게 답변이 나왔다.
  • 검색과 LLM 이 GPU 에서 서로를 밀어내며 매 턴마다 5~10초씩 추가로 기다려야 했다.
💡 해결 전략 (Node-level Resource Pivot)
  • 각 노드가 끝나면 임베더를 해제하고 2초 대기 시켜 다음 노드가 깨끗한 GPU 에서 시작하게 했다.
  • 답변 노드 진입 직전 Ollama 를 강제로 내렸다가 다시 올려 LLM 의 GPU 적재를 보장했다.
  • 이 패턴을 _release_and_wait() 한 함수로 묶어 10개 노드 전체에 동일 적용 해 OOM 경로 자체를 차단했다.
✓ 최종 결과
턴당 14.5초 의 추가 대기를 받아들이고 OOM 발생 0·답변 누락 0 을 확보하여 운영을 안정화했다.
